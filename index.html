Staff Ratio System — Firebase Setup
One-time setup required. This app uses Google Firebase for real-time sync across all devices. Follow the steps below to connect your Firebase project, then this page will never appear again on this device.
How to get your Firebase config
Complete these steps in the Firebase Console (free tier is sufficient)
1
Go to console.firebase.google.com → Create a new project (e.g. tema-hospital)
2
In the project, go to Project settings → Your apps → Add app → Web. Register the app and copy the config object shown.
3
Go to Build → Firestore Database → Create database → Start in test mode → choose your region.
4
Paste each value from the Firebase config object into the fields below and click Connect.
Firebase project credentials
All fields are required. Values are saved locally on this device only.
